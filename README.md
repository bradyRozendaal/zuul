HOW TO COMPLETE THE GAME

Start in the Entrance Lobby (Room 0).

Travel to Reception (Room 1) and collect the Keycard.

Take the Keycard to the Security Office (Room 2) and use it to
gain security access.

Travel to Storage Room (Room 4) and collect the Screwdriver.

Travel to Maintenance (Room 10) and collect the Fuse.

Go to the Generator Room (Room 11). Use the Screwdriver to open
the generator panel, then use the Fuse to restore power.

Travel to the Research Laboratory (Room 7) and collect the Battery.

Take the Battery to the Server Room (Room 6) and use it to bring
the server online.

Travel to the Offices (Room 9) and collect the Access Code.

Go to the Elevator (Room 13). Once power has been restored, the
server is online, and security access has been granted, use the
Access Code to unlock the elevator.

Travel north from the Elevator (Room 13) to the Emergency Exit
(Room 14) to complete the game.
